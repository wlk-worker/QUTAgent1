## 2. 智能体赛道硬性约束

- 智能体**独立参赛**，正式任务期间无人工注入赛题分析、提示、代码、指令或答案。
- 解题 Agent **无公网访问**，只能访问授权平台接口、大模型网关和题目入口；不得通过代理/重定向/子进程绕开。
- 工具和依赖必须**预装**；评测期不下载公网依赖。
- 初选赛/入围阶段可用团队自有 API key，通过网关访问官方白名单模型；正式赛仅可访问主办方提供的智谱模型，Token 总量 1B。
- 只能攻击平台明确授权的赛题目标；不得攻击平台基础设施、模型网关、镜像仓库、其他队伍或外部系统。
- 动态 Flag 按赛道/队伍/实例生成；只能提交本队授权实例实际取得的 Flag；禁止爆破提交接口、跨队 Flag 或平台漏洞获利。
- 正式赛题只接受 **Web、Pwn、AI Security** 在线交互类；出题队伍不得通过本队题得分。

## 3. CTFY-0001 schema v3 关键变化

平台文档明确为 v3（2026-10-30 不兼容版本，2026-11-04 增补）：

1. **平台已经启动 target**：`task.json.target_instance` 存在；Agent **不得** `POST /api/v1/instances`（会 403 `token_missing_scope`）。token 只覆盖本次 challenge。
2. **target 地址**：`target_endpoints` 给出玩家可见地址；恰好一个 Web 端点时还有 `CTFY_TARGET_URL`。不需要再调用平台查询 target。
3. **附件已经在本机**：挑战附件在 `/ctfy/work/attachments/`；`task.json.attachments[]` 给出 `name/size/path`，超过 4 MiB 的 `path` 可能为 null，此时用 `GET /api/v1/instances/{target_instance}/attachments/{name}`。
4. **result.json 可选但必须 schema 3**：推荐写 `{"schema_version":3,"answers":{...},"stop_reason":...}`；stdout 对用户镜像不参与评分；`result.json` 由平台读取。
5. **rounds**：平台可能在同一工作目录重启最多 5 轮；每轮重新写 `result.json`；保留工作目录中的 notes/scripts。新题/重试在 README 说明。
6. **qa**：没有 target；附件同样在 `attachments/`；没有模型调用会记录为无环境错误。
7. **engagement/defence/awd**：v3 还定义了这些 run_mode；智能体赛道当前重点是标准 Web/Pwn/AI 在线题，本项目不声称支持 engagement/awd。

## 5. 仍需在赛前确认

- 正式赛智谱模型的具体 `LLM_MODEL`/`LLM_BASE_URL`/额度注入方式，以平台任务环境为准。
- 镜像审核截止时间、是否允许在入围后更新镜像；规则只说明允许窗口和登记要求。
- 平台是否对 `writeup`/运行记录有额外要求；当前 Agent 写 `result.json`，可由运行归档复盘。
- 智能体赛道是否要求提交出题包；本项目 `author/` 可生成，但上传仍需人工按平台流程。
