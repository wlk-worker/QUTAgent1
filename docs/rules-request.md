# 赛道规则询问清单（可直接发给组委会）

> 目的：拿到智能体赛道专属规则，替代目前只能从公开配置推断的字段。以下问题按“会改变实现”排序；发送前请确认报名队伍/账号信息，不要附带个人手机号等无关信息。

## 一、最小材料

请优先提供以下任意一种：

1. **《智能体赛道赛事规则》附件**（官网规则页文字提到“智能体赛道附件中的赛事规则文档”）；
2. 附件下载链接，或登录可见的规则页 URL；
3. 若暂时不能提供，请对下面问题逐条给出文字答复。

获取路径：登录 `ctfy.tsinghua.edu.cn` → 比赛详情/规则页 → 查看“附件”区域；同时检查站内消息、收件箱、队伍页是否在报名审核通过后开放附件。若页面仍无入口，请通过比赛消息页的“联系组委会”、QQ 群 **1053114117** 或官方 Discord 询问。

## 二、必须确认的问题

### A. 镜像与运行

1. 镜像提交/冻结的截止时间？是否必须在初赛前完成审核？
2. 允许的镜像仓库（平台 registry / ghcr.io / 其他）？是否允许公开镜像？digest 固定后如何更新？
3. 人工审核大概需要多久？初赛后能否更新镜像并重新审核？
4. 比赛时 agent 是每道题启动一次，还是整场启动一次？单次运行的时间上限、最大轮数、`max_turns` 是否由平台注入？
5. 每队同时可运行的实例数是否确实为 1？评测并发数是多少？

### B. 模型与额度

6. 比赛是否限定模型白名单？是否只能用主办方供给的模型？
7. 每队/每题的 token、费用、请求数额度是多少？超出会怎样（截断/失败/扣分）？
8. agent 能否使用自己的模型 API key？若可以，允许哪些 endpoint？
9. 平台是否提供 `LLM_BASE_URL`/`LLM_API_KEY` 的正式额度说明，还是需要队伍自己充值？

### C. 解题范围与计分

10. 解题范围是否只限在线交互类（Web/Pwn/AI 安全）？是否包含 Crypto/Reverse/Misc 离线题？
11. 初赛与决赛各多少题？题目何时公布？是否同一套题？
12. 主榜是否只按 `flags_solved → solved → last_solve_at` 排序？是否另有部分分/难度权重？
13. 智能体 entry 与人类报名队伍、奖项归属是什么关系？“Agent 独立参赛、不算在人类队伍里”具体如何映射到团队奖项？
14. 初赛晋级规则（前多少名/比例）？未晋级队伍是否还有成绩或奖项？

### D. 出题

15. 赛时是否**强制**自主出题？出题是否计入主榜分数，还是只评“创新挑战”单项奖？
16. 出题窗口是否只有 11-21 的三个 2 小时段？每窗口最多提交几道计分题？UI 显示的“2 小时 5 次上传/3 个待审”与配置字段“每窗口 1 次”如何区分？
17. 出题是否允许赛前准备模板/参数化生成？是否要求题目在赛时由 agent 自主选择、验证并上传？
18. 出题程序应如何获得上传权限？是否使用 `agent_author` token（`authoring: write`）、平台消息发放，还是必须由人在网页上传？
19. AI 安全题在 CTFY-0002 中没有独立 category，应使用 `web` 还是 `misc`？允许哪些 tags？
20. 上传后的人工审核/smoke 时限是多少？被拒后能否在同一窗口重传？题目是否会被纳入比赛供其他 agent 解？

### E. 提交与合规

21. 答案提交是否有每题错误次数上限？动态 flag/checker 题是否不限次？
22. 是否允许 agent 读取平台 scoreboard、题目列表、附件、writeup？eval token 的实际 scope 是什么？
23. 比赛期间是否允许队伍在平台外运行自己的 agent（例如出题阶段）？如何审计“无人工介入”？
24. 是否允许使用外部网络/搜索？比赛配置显示 `internet_policy: deny`，是否对所有题型生效？
